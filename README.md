# WhatsApp Media Downloader Bot

A production-ready WhatsApp bot for downloading media from YouTube, TikTok, Instagram, Twitter, and 1000+ other platforms using yt-dlp.

## Features

- 📥 Download videos and audio from 1000+ platforms
- 🎯 Interactive quality selection
- 📊 Real-time progress tracking
- ⚡ Concurrent download support
- 🗑️ Automatic file cleanup
- 📦 Cloudflare R2 storage
- 🔄 Auto-reconnection
- 👥 Multi-user support
- 🚦 Rate limiting
- 📝 Comprehensive logging

## Prerequisites

- Node.js 18+
- Python 3.6+
- yt-dlp
- ffmpeg
- Cloudflare R2 account
